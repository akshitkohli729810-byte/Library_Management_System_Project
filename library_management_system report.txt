## 4. DATABASE STRUCTURE

The project uses a database named **LibraryDB**, which consists of three main tables. Each table stores a different category of information.

### 4.1 Students Table

The Students table contains the personal and academic details of students registered in the library.

Columns:
- Student_ID – Unique identification number of each student (Primary Key).
- Student_Name – Full name of the student.
- Department – Department in which the student studies.
- Email – Student's email address.
- Phone – Contact number of the student.

### 4.2 Books Table

The Books table maintains information about the books available in the library.

Columns:
- Book_ID – Unique identification number of each book (Primary Key).
- Title – Name of the book.
- Author – Name of the book's author.
- Publisher – Publishing company.
- Quantity – Total copies of the book.
- Available_Quantity – Number of copies currently available.

### 4.3 Book_Issue Table

This table maintains records of books borrowed by students and their return status.

Columns:
- Issue_ID – Unique ID for every issue record (Primary Key).
- Student_ID – Identifies the student borrowing the book (Foreign Key).
- Book_ID – Identifies the borrowed book (Foreign Key).
- Issue_Date – Date on which the book was issued.
- Return_Date – Date of book return.
- Status – Current condition of the issue record (Issued or Returned).

## 5. DATABASE RELATIONSHIPS

The project uses relationships between the three tables to connect student information with book records.

The relationships are as follows:

1. A single student can borrow multiple books, resulting in multiple issue records.
2. A particular book can be issued to different students at different times.
3. The Book_Issue table acts as a connecting table between Students and Books.

Primary keys help identify individual records, whereas foreign keys establish connections between tables and maintain data consistency.

## 6. SQL CONCEPTS IMPLEMENTED

Different SQL concepts were applied while developing the database.

### 6.1 DDL (Data Definition Language)

DDL commands are used to create and define the database and its tables.

Commands used:
- CREATE DATABASE
- CREATE TABLE

### 6.2 DML (Data Manipulation Language)

DML commands help insert new information and make changes to existing records.

Commands used:
- INSERT
- UPDATE

### 6.3 DQL (Data Query Language)

The SELECT command is used to fetch information from the database according to specific requirements.

### 6.4 Constraints

Constraints help maintain accuracy and prevent invalid data from being stored.

The following constraints are used:

- PRIMARY KEY: Gives every record a unique identity.
- FOREIGN KEY: Creates relationships between tables.
- NOT NULL: Does not allow a column to contain NULL values.
- UNIQUE: Prevents duplicate values, such as email addresses.
- CHECK: Applies conditions to the values entered in a column.
- AUTO_INCREMENT: Automatically generates ID numbers for new records.

### 6.5 Aggregate Functions

Aggregate functions are used to perform calculations on multiple records.

- COUNT(): Finds the total number of records.
- SUM(): Calculates the sum of numerical values, such as total book copies.

### 6.6 SQL Joins

Joins are useful when information is stored in different tables but needs to be displayed together.

The project uses:

- INNER JOIN: Displays matching records from related tables.
- LEFT JOIN: Displays all records from the left table along with matching records from the right table.

## 8. SAMPLE SQL QUERIES

Some important SQL queries executed in the project are shown below.

1. Fetch all student records

```sql
SELECT * FROM Students;
```

2. Display all books stored in the database

```sql
SELECT * FROM Books;
```

3. Find books that are currently available**

```sql
SELECT *
FROM Books
WHERE Available_Quantity > 0;
```

4. Display books borrowed by a particular student**

```sql
SELECT
    S.Student_Name,
    B.Title,
    B.Author,
    I.Issue_Date,
    I.Status
FROM Book_Issue I
INNER JOIN Students S
ON I.Student_ID = S.Student_ID
INNER JOIN Books B
ON I.Book_ID = B.Book_ID
WHERE S.Student_Name = 'Rahul Sharma';
```

5. Find the total number of students**

```sql
SELECT COUNT(*) AS Total_Students
FROM Students;
```

6. Calculate the total number of book copies**

```sql
SELECT SUM(Quantity) AS Total_Books
FROM Books;
```
